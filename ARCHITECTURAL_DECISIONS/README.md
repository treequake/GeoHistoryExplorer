# Architecture Decision Records

This directory records architectural decisions that shape repository structure, data model design, workflow boundaries, and scientific integrity.

Each ADR should include:

- decision
- status
- context
- chosen approach
- viable alternatives
- why alternatives were rejected or deferred
- consequences
- expected cost of changing the decision later

ADRs are part of the scientific audit trail. They should be updated by adding new ADRs rather than silently rewriting project history.
